# YASHVI - Navratri Official PWA

A mobile-first, installable Progressive Web Application (PWA) replicating the official Yashvi Navratri event ticket and passes experience.

## Features
- **PWA Installation**: Works on both iPhone (iOS Safari) and Android (Chrome).
- **Auto Install Prompt**: Prompts to install immediately when opened in a mobile browser.
- **5-Pass QR Horizontal Carousel**: Horizontally scrollable and swipeable ticket passes `[1/5]` to `[5/5]`.
- **Exact Visual Replica**: 100% faithful design from original screens (Launch screen, Home screen, Ticket screen, My Account screen).
- **Service Worker Offline Support**: Full offline caching via Service Worker.

## Deployment on Render
1. Create a new **Static Site** on Render.
2. Connect this repository: `dishantkasodariya/Navratri`.
3. Set **Publish directory** to `./` (or leave blank).
4. Deploy!
